# Actualización — SETS Framework 1.4.0 → 1.4.1

## Propósito

Hacer explícita la apertura del aprendizaje sin convertir SETS en un sistema sin foco. Esta versión no crea una nueva disciplina, no añade un currículo común ni cambia los contratos de progreso y cierre.

## Cambios

- Las tecnologías familiares son contexto opcional, no whitelist ni stack predeterminado.
- Los currículos son mapas de competencias prioritarias, no catálogos cerrados.
- Los casebooks son colecciones iniciales; el caso conductor no es obligatorio en cada sesión.
- La profundidad se adapta entre fundamentos, profundización y especialización, sin etapas obligatorias.
- La apertura queda limitada por la misión del Proyecto: no divagar ni importar progreso de otros proyectos.
- Se añaden checks Q27–Q32. Están definidos, no se consideran aprobados hasta ejecutarlos.

## Aplicación

1. Actualiza el repositorio `sets-framework` con los archivos de esta versión.
2. Reemplaza en cada Proyecto de ChatGPT las instrucciones activas y las fuentes del framework por las actualizadas.
3. Actualiza cada programa según su propio paquete v1.5.1.
4. Conserva el historial Git y las evidencias reales; no reinicies ni inventes progreso por esta actualización.
5. Ejecuta los checks relevantes y registra `OK / Falla / Sin probar` con evidencia breve.

La sincronización entre GitHub y los archivos adjuntos del Proyecto de ChatGPT sigue siendo manual salvo que una operación de escritura real confirme lo contrario.
